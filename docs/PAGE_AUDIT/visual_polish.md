# جولة التحسين البصري — هوية مركز طبي

## ما تغيّر
- أُضيف `static/css/medical-polish.css` ويُحمّل أخيراً في كل shells (base/platform/portal/kiosk) عبر `config.py`.
- **لوحة الألوان:** تيل طبي `#0e7490` → زمردي `#059669` → سماوي `#06b6d4`. أُزيل التدرّج الأزرق→برتقالي من شريط البوابة ولافتات اللوحات (كان يأتي من لون accent القديم).
- **الأزرار:** `.btn-primary` الآن تيل موحّد مع نص أبيض، `.btn-info` سماوي، ارتفاع ونصف قطر متسقان.
- **القائمة الجانبية:** عنصر نشط بتظليل تيل فاتح وحدّ جانبي بدل الأزرق الداكن.
- **البطاقات:** حدود خفيفة، انحناء 14px، ظل ناعم، ترويسة بتظليل تيل خفيف.
- **الجداول:** رؤوس رمادية فاتحة، تباعد صفوف مريح، تظليل خفيف عند المرور.
- **خبز التنقل:** فواصل `/` واضحة ومسافات تمنع التصاق `HomeDoctor`.
- **ال بوابة:** شريط علوي تيل→زمردي، عنصر تنقّل نشط تيل.
- حدّثت العلامة التجارية لمستأجر المنصة عبر واجهة branding إلى التيل/الزمردي.

## التحقق البصري
- جولة كاملة أُعيد التقاط 389 لقطة بعد التحسين (`walk_log_polish.txt`) — **0 خطأ 500 / 0 علامة خطأ**.
- لقطات مقارنة في `visual_recheck/`:
  - `doctor_dashboard.png` — اللافتة تيل→زمردي بدل أزرق→برتقالي.
  - `reception_patients.png` — أزرار موحّدة وجدول أنظف.
  - `portal_dashboard.png` — شريط بوابة تيل.
  - `manager_units.png` — بطاقات وحدات مرتّبة.
- `npx stylelint static/css/medical-polish.css` نظيف.

## ملاحظة
