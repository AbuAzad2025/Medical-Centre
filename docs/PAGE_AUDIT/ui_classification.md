## ملاحظة منهجية
كل عنصر في جدول «يعمل» مُختبر بضغط فعلي أو بطلب API حقيقي من متصفح، لا بقراءة الكود فقط. ما لم يُختبر يُصنَّف «جزئي» أو «واجهة فقط» بدل افتراض أنه يعمل.
