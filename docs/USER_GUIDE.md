# دليل المستخدم — User Guide

> دليل عملي لمستخدمي المركز (استقبال، طبيب، ممرض، مختبر، أشعة، صيدلية، محاسب، مدير). آخر تحقق من الكود: **5 أغسطس 2026** — الإصدار 3.1.

---

## 1. تسجيل الدخول

- افتح عنوان المنصة (مثال: `http://localhost:8080`).
- أدخل البريد الإلكتروني وكلمة المرور (مفصولة لكل دور).
- في النظام السحابي يُختار المركز (tenant) تلقائياً حسب النطاق/المسار.
- بعد قفل حسابات الدخول: تفعيل MFA أو WebAuthn إذا كانت المنصة مفعّلة.

---

## 2. الاستقبال (`reception`)

- **تسجيل مريض جديد:** اسم (ثلاثي/رباعي)، هوية، جهة اتصال، بيانات طبية أساسية (حساسية، تشخيصات سابقة).
- **فتح زيارة:** اختر القسم/الطبيب — تُنشئ طابوراً للعيادة.
- **المواعيد:** جدولة أو حجز من البوابة الإلكترونية للمريض.
- **متابعة الحالة:** المريض في انتظار العيادة أو المختبر أو الصيدلية.

---

## 3. الطبيب (`doctor`)

- لوحة اليوم: قائمة الزيارات المعلقة.
- فتح زيارة → نموذج **SOAP**: شكوى (Subjective)، فحص (Objective)، تقييم (Assessment)، خطة (Plan).
- **التشخيص:** ترميز ICD-10 (مدوّن) + إجراءات CPT.
- **الروشيتة (e-prescription):** أدوية مع جرعات ومدة، مع فحص التفاعلات الدوائية (drug interactions).
- **طلب مختبر / أشعة** بضغطة — يصل لقوائم العمل.
- **نماذج التخصص الديناميكية** (نموذج الحشو) → راجع [DYNAMIC_FORM_GOVERNANCE.md](DYNAMIC_FORM_GOVERNANCE.md).
- **التوقيع الإلكتروني** للتقارير والنتائج عند تفعيل القدرة.
- **الاستشارات عن بعد** (telemedicine) حسب التفعيل.

---

## 4. المختبر (`lab`)

- **قائمة العمل:** طلبات التحاليل الواردة.
- **سحب العينة:** تأكيد الاستلام وتسجيل المعرّف (باركود).
- **إدخال النتائج:** قيم مع نطاقات مرجعية (رقمياً أو نصياً).
- **اعتماد النتيجة:** خطوة تحقق قبل التحرير للمريض.
- **ضبط الجودة:** سجلات QC ومراقبة الكواشف (`enable_lab_qc`).

---

## 5. الأشعة (`radiology`)

- استقبال الطلب → التقاط الصورة / رفع ملف (DICOM إن فُعّل).
- مسودة تقرير → توقيع → نشر.
- **AI Imaging** (عند التفعيل): تحليل تلقائي للصور وتقارير مساعدة.

---

## 6. الصيدلية (`pharmacy`)

- **صرف روشيتة:** تأكيد التوافر، الصرف، وخصم المخزون.
- **بيع مباشر (POS):** بيع بدون روشيتة — فاتورة صيدلية.
- **المخزون:** جرد، شراء، استلام، تحويلات، تنبيه انخفاض المخزون، باركود.
- **أدوية خاضعة للرقابة:** سجل صرف خاص (`controlled_medications`).

---

## 7. التمريض (`nursing`)

- **العلامات الحيوية:** تسجيل قياسات الزيارة/الجناح.
- **الفرز (triage):** تقييم أولوية الطوارئ.
- **إدارة الأدوية (eMAR):** جدولة جرعات، تأكيد الصرف للمريض، سجل `medication_administration_logs`.
- **إدارة الأسرّة والأجنحة** (`bed_management`).

---

## 8. الفوترة (`billing`)

- إنشاء فاتورة من خدمات الزيارة (دواء/تحليل/أشعة/جلسة).
- تسجيل دفعة (نقدي/بطاقة/تحويل) → إيصال تلقائي.
- أقساط وتحصيل وديون (`installments`, `debt_management`).
- فواتير تأمين مع شركات التأمين (`insurance_billing`).
- مرجع تفصيلي: [AUDIT_PAYMENTS_BILLING.md](AUDIT_PAYMENTS_BILLING.md).

---

## 9. المحاسب والمدير (`accountant` / `manager`)

- **التقارير:** مالية يومية/شهرية، إيرادات المصادر، مصروفات، أداء الأقسام.
- **مستودع البيانات** (`data_warehouse`) و **التحليلات** (`what-if`) عند التفعيل.
- **التسعير:** قائمة الخدمات والأسعار والأسعار الخاصة.
- **الفريق:** مستخدمون، أدوار، صلاحيات، جداول عمل، إجازات.

---

## 10. المالك (SaaS — `owner`)

- إدارة المستأجرين (مراكز) وحالاتهم: `TRIAL` / `ACTIVE` / `PENDING` / `SUSPENDED` / `CANCELLED`.
- إنشاء مراكز يدوياً أو عبر التسجيل الذاتي (Stripe).
- تخصيص الباقات والوحدات لكل مركز (الاستفادة من `product_bundles`).
- مؤشرات المنصة الكلية والفوترة (`analytics_global`).

---

## 11. بوابة المريض (`portal`)

- حجز موعد عبر الإنترنت (مع/بدون دفع حسب الإعداد).
- عرض النتائج والتقارير.
- متابعة الفواتير والدفع الإلكتروني.
- تعبئة استبيانات الرضا.

---

## الأسئلة الشائعة

**هل يرى المريض نتائج المختبر فوراً؟**
لا — النتيجة تمر بالاعتماد (validation) أولاً ثم تُحرر.

**هل يمكن لمحاسب رؤية بيانات طبية؟**
الصلاحيات تحددها الأدوار والوحدات — الفوترة لا تتضمن ملف المريض الطبي.

**كيف أضيف نموذج تخصص جديد؟**
يُنشئه `manager`/`admin` من `/specialty-forms/new` — خطوات مفصلة في عقد النماذج الديناميكية.

---

## تنبيهات

- لا تشارك كلمة المرور — النظام يسجل محاولات الدخول الفاشلة والجلسات.
- الروشيتات والأوامر السريرية تحمل توقيعاً وتاريخاً.
- أي تعديل في الأسعار يتم عبر لوحة التسعير وليس عبر قاعدة البيانات مباشرة.
