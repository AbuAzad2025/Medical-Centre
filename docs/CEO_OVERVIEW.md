# نظرة عامة تنفيذية — Executive Overview

**آخر تحقق من الكود:** 5 أغسطس 2026 — الإصدار **3.1**

---

## ما هي المنصة؟

منصة سحابية (SaaS) متعددة المستأجرين لإدارة المراكز الطبية: الاستقبال، الأطباء، المختبر، الأشعة، الصيدلية، الطوارئ، التمريض، الفوترة، المخزون، المواعيد، التقارير، بوابة المريض، لوحة المالك، التصوير بالذكاء الاصطناعي، والتكامل (FHIR/SSO/DICOM).

**نموذج العمل:** تشترك المراكز في باقات شهرية (22 باقة قابلة للبيع + باقة مخصصة). بيانات كل مركز معزولة تماماً (RLS على مستوى قاعدة البيانات).

## كتالوج الباقات (23)

استعلام مباشر:

```sql
SELECT slug, name_ar, monthly_price FROM product_bundles WHERE is_active ORDER BY monthly_price;
```

| النطاق | أمثلة |
|--------|-------|
| منخفض (< 500) | فوترة ومواعيد فقط (199)، عيادة طبيب خاص (299)، صيدلية مستقلة (499)، عيادة طبيب باستقبال (499) |
| متوسط (500–1500) | مختبر مستقل (599)، عيادة صغيرة (799)، أشعة مستقلة (799)، عيادة مع مختبر (1199)، عيادة مع أشعة (1299) |
| عالٍ (> 1500) | عيادة طبيب متكاملة (1499)، دار رعاية تمريضية (1599)، عيادة مع مختبر وأشعة (1799)، مركز صحي مجتمعي (1999)، مركز طبي متعدد الأقسام (2499)، مجمع عيادات (3499)، مستشفى كامل (5999) |
| خاص | حزمة مخصصة (`custom` — سعر 0، تُعد يدوياً) |
