## Work

### Fix 1 — `DetachedInstanceError` in `tests/integration/test_feature_gating.py` (the pasted CI failure)
- `_saas_default_tenant_context` called `ensure_default_test_tenant(app)` → returns a
  `Tenant` that is **expired + detached**: `ensure_default_test_tenant` commits in its
  own `with app.app_context(), app.test_request_context():` block, and the app-context
  teardown (`Flask-SQLAlchemy` scoped-session removal + `expire_on_commit=True`)
  detaches/expired it. The conftest-local `bind_tenant_on_g` then did `tenant.id` →
  `DetachedInstanceError`.
- Fix: use `tests.tenant_context.bind_tenant_on_g` (detached-safe) in the autouse fixture.
- Verified: 21 passed.

### Fix 2 — `rollback_db` fixture was broken (AttributeError: session_maker)
- 094e217 rewrote `rollback_db` to `_db.session = _db.session_maker(bind=conn)`, but
  Flask-SQLAlchemy 3.1.1 has no `session_maker`. Every `rollback_db` test errored.
- Fix: restored the pre-094e217 mechanism (`engine.connect()` + transaction +
  patching `flask_sqlalchemy.session.Session.get_bind` onto one connection +
  `join_transaction_mode='create_savepoint'`).
- Verified: test_currency_service.py (rollback_db) 14 passed.

### Fix 3 — `Popped wrong request context` across 23 tests (NEW CI run pasted by user)
- Root cause: 094e217 REMOVED the conftest `client` fixture
  (`def client(app): return app.test_client()`). Without it, tests resolve pytest-flask's
  `client`, whose definition is `with app.test_client() as client: yield client` — a
  context manager that pushes an EXTRA app context for the whole test.
- Stack corruption:
  `[myapp appctx] -> [_saas_default_tenant_context app+request ctx] -> [pytest-flask client appctx] -> [test app+request ctx] -> [client.post request ctx]`
  The extra app context breaks pop order when tests do
  `with app.test_request_context(): client.post(...)` → "Popped wrong request context".
- Fix: restore `def client(app): return app.test_client()` (plain, non-CM) to override
  pytest-flask's. Faithful to pre-094e217.
- Verified: 71 tests across test_add_service_without_reopening,
  test_archive_lockdown, test_billing_visit_ownership, test_custom_service_lifecycle,
  test_feature_gating → all pass.
