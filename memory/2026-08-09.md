## Key findings
- `EncryptedString._get_service()` rebuilds `FieldEncryptionService` on every column access → PBKDF2 480k iterations (~2.5s each). Added an autouse `_cached_encryption` fixture to cache one service instance; semantics unchanged. This unblocked list pages (queue add-patient GET went from hanging to ~11s).
- Local persistent test DB accumulated 4235 patients / 3506 visits from interrupted runs; list pages decrypting all rows become minutes-long. CI uses a fresh PG per job so not affected.
- add_patient GET redirects to `/reception/patients?show_add=1` when `show_add` param absent.
- delete_patient requires `manager` (via `@can_delete_patient`); reception gets 403.
- checkin sets status CONFIRMED not CHECKED_IN (confirmed-by-appointment flow).
- create_appointment POST expects `appointment_date` + `appointment_time`, not a single `starts_at`.
- allergy/problem APIs need JSON body (`allergen`, `problem_description`) + content_type json.
- api/available-times needs `doctor_id` + `date` query params.
- Payment model field is `method` (not `payment_method`); archive requires gl_posted_at + full payment.
